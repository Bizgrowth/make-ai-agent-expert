# Clients

One folder per client: `clients/<client-slug>/` containing `brief.md`, `design.md`, `build-log.md`, `review.md`, `test-report.md`, `process-doc.md` (and `loom-script.md` if requested).

Rules:
- Slug is lowercase-with-dashes; no personal data in folder names.
- Store anonymized samples only. Never commit credentials, API keys, webhook secrets or real customer records.
