# Portfolio Kit Checklist

Complete once per build, then cut down per platform. Nothing is posted without owner approval.

## 0. Real-client permission (do this first for any real-client work)
- [ ] **Written permission** from the client to use their name, logo, quote or data. Date: ____ Stored at: ____
- [ ] If no permission: anonymized, and no identifying details in screenshots, text or recordings
- [ ] If demo only: clearly labelled "Demo project, synthetic data"

## 1. Kit contents (build once)
- [ ] Case study, short and long versions (`templates/case-study.md`)
- [ ] Flow Studio recording of the main run (strongest asset, lead with it)
- [ ] Screenshots with no client data or secrets
- [ ] Test report excerpt
- [ ] Process document excerpt (what it does, how to pause it)
- [ ] Testimonial slot: empty until a real written quote exists
- [ ] Every number linked to how it was measured

## 2. Cut per platform
- [ ] **Upwork:** fixed-scope offer with a clear first step; short case study; proposal template
- [ ] **Fiverr:** three tiers with a clear difference; short description; gallery assets
- [ ] **LinkedIn:** short case study plus the recording
- [ ] **Website:** long case study, proof, one clear call to action
- [ ] Check each platform's own help page for current image sizes, video length, listing fields and link or contact rules before exporting (limits change; none are stated here)

## 3. Honesty checks
- [ ] No invented testimonials, metrics or logos
- [ ] Demo not presented as a client result
- [ ] Estimates marked as estimates
- [ ] No secrets, webhook URLs, keys or real customer data visible anywhere

## 4. Maintenance
- [ ] Reviewed on: ____ (every quarter)
- [ ] Removed anything that no longer matches how you work
